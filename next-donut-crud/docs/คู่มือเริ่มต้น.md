# คู่มือเริ่มต้นแก้ไขและใช้งานโปรเจกต์

คู่มือนี้อธิบายวิธีแก้ตาราง เพิ่มข้อมูล เขียน API และหน้าเว็บในโปรเจกต์
Next.js 16, React 19, Prisma 6.19 และ SQLite

## 1. เปิดโปรเจกต์และรันเว็บไซต์

เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วใช้คำสั่ง:

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) ในเบราว์เซอร์
หยุดเซิร์ฟเวอร์ด้วย `Ctrl+C`

คำสั่งที่ใช้บ่อย:

```bash
npm run dev          # เปิดเว็บสำหรับพัฒนา
npm run lint         # ตรวจรูปแบบและข้อผิดพลาดในโค้ด
npm run typecheck    # ตรวจ TypeScript
npm run build        # ทดลอง build แบบ production
npx prisma studio    # เปิดหน้าดูและแก้ข้อมูลในฐานข้อมูล
```

## 2. แก้ไขตารางใน Prisma schema

ไฟล์ schema อยู่ที่ `prisma/schema.prisma` ปัจจุบันมี `Book`, `Review` และ
`Employee` ตัวอย่างเช่น การเพิ่มจำนวนหน้าหนังสือทำได้โดยเพิ่มฟิลด์ใน `Book`:

```prisma
model Book {
  id          Int       @id @default(autoincrement())
  title       String
  author      String
  price       Float     @default(0)
  stock       Int       @default(0)
  pageCount   Int       @default(0) // ฟิลด์ใหม่
  publishedAt DateTime  @default(now())
  coverUrl    String?
  reviews     Review[]
}
```

ชนิดข้อมูลที่ใช้บ่อย:

| Prisma type | ใช้เก็บ | ตัวอย่าง |
|---|---|---|
| `String` | ข้อความ | ชื่อ, อีเมล |
| `Int` | จำนวนเต็ม | สต๊อค, จำนวนหน้า |
| `Float` | เลขทศนิยม | ราคา |
| `Boolean` | จริง/เท็จ | สถานะ |
| `DateTime` | วันและเวลา | วันที่ตีพิมพ์ |
| `String?` | ข้อความที่เว้นว่างได้ | URL รูปปก |

`@default(0)` กำหนดค่าเริ่มต้น ส่วน `?` หมายถึงยอมให้ไม่มีค่า
การเพิ่มฟิลด์ที่จำเป็นในตารางที่มีข้อมูลอยู่แล้วควรกำหนด `@default(...)`
หรือทำฟิลด์เป็น optional ก่อน เพื่อให้ข้อมูลเดิมยังใช้ได้

### เพิ่มตารางใหม่

ตัวอย่างตารางหมวดหมู่และความสัมพันธ์กับหนังสือ:

```prisma
model Category {
  id     Int    @id @default(autoincrement())
  name   String
  books  Book[]
}

model Book {
  id         Int       @id @default(autoincrement())
  title      String
  categoryId Int?
  category   Category? @relation(fields: [categoryId], references: [id])
  // ฟิลด์และความสัมพันธ์เดิมของ Book
}
```

ความสัมพันธ์ `Category.books` กับ `Book.category` เป็นแบบหนึ่งหมวดหมู่มีหนังสือ
ได้หลายเล่ม (1-to-N) ถ้าเพิ่ม relation ให้ตรวจว่าทั้งสองฝั่งมี relation field
และ foreign key ถูกต้อง

หลังแก้ schema ให้ sync ฐานข้อมูลและสร้าง Prisma Client ใหม่:

```bash
npx prisma format
npx prisma validate
npx prisma db push
npx prisma generate
```

`db push` ปรับ SQLite ที่ `prisma/dev.db` ให้ตรงกับ schema โดยตรง
ก่อนลบหรือเปลี่ยนชนิดฟิลด์ ควรสำรองฐานข้อมูลก่อน เพราะอาจทำให้ข้อมูลเดิมหาย
ไฟล์ฐานข้อมูลอยู่ที่ `prisma/dev.db`

## 3. เพิ่มข้อมูลลงฐานข้อมูล

### เพิ่มผ่าน Prisma Studio

เปิดหน้าจัดการฐานข้อมูล:

```bash
npx prisma studio
```

เลือกตาราง `Book`, `Employee` หรือ `Review` แล้วเพิ่มข้อมูลผ่านหน้าเว็บ
รีวิวต้องระบุ `bookId` ที่มีอยู่จริง

### เพิ่มผ่าน API ที่มีอยู่

เพิ่มหนังสือส่ง `multipart/form-data` ไปที่ `POST /api/books` ตัวอย่างจาก
หน้าเว็บใช้ `FormData`:

```ts
const formData = new FormData();
formData.set("title", "ตัวอย่างหนังสือ");
formData.set("author", "ชื่อผู้แต่ง");
formData.set("price", "250");
formData.set("stock", "10");
formData.set("publishedAt", "2026-01-15");

const response = await fetch("/api/books", {
  method: "POST",
  body: formData,
});
```

เพิ่มพนักงานส่ง JSON ไปที่ `POST /api/employees`:

```ts
const response = await fetch("/api/employees", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({
    firstName: "สมชาย",
    lastName: "ใจดี",
    phone: "0812345678",
    email: "somchai@example.com",
    position: "พนักงาน",
  }),
});
```

อีเมลพนักงานต้องไม่ซ้ำกัน สามารถดูรายการด้วย `GET /api/employees`
และดูหนังสือพร้อมรีวิวได้ด้วย `GET /api/books`

## 4. เพิ่มหรือแก้ API

API ของ Next.js App Router วางไว้ใน `src/app/api/`:

| ไฟล์ | Endpoint | หน้าที่ |
|---|---|---|
| `src/app/api/books/route.ts` | `/api/books` | แสดงรายการและเพิ่มหนังสือ |
| `src/app/api/books/[id]/route.ts` | `/api/books/:id` | ดู แก้ไข หรือลบหนังสือ |
| `src/app/api/books/[id]/reviews/route.ts` | `/api/books/:id/reviews` | เพิ่มรีวิวให้หนังสือ |
| `src/app/api/employees/route.ts` | `/api/employees` | แสดงรายการและเพิ่มพนักงาน |
| `src/app/api/employees/[id]/route.ts` | `/api/employees/:id` | แก้ไขหรือลบพนักงาน |

ตัวอย่างการอ่านข้อมูลด้วย Prisma:

```ts
const books = await prisma.book.findMany({
  include: { reviews: true },
  orderBy: { id: "desc" },
});

return NextResponse.json(books);
```

ตัวอย่างการเพิ่มข้อมูล:

```ts
const employee = await prisma.employee.create({
  data: {
    firstName: "สมชาย",
    lastName: "ใจดี",
    phone: "0812345678",
    email: "somchai@example.com",
    position: "พนักงาน",
  },
});

return NextResponse.json(employee, { status: 201 });
```

เพิ่ม `GET`, `POST`, `PUT` หรือ `DELETE` เป็น exported function ในไฟล์
`route.ts` ตรวจ input ก่อนเรียก Prisma และส่ง error status ที่เหมาะสมกลับไป
ห้ามรับข้อมูลจาก request แล้วส่งเข้า Prisma โดยไม่ตรวจชนิดและค่าที่จำเป็น

## 5. เพิ่มช่องกรอกหรือแสดงผลบนหน้าเว็บ

หน้าเว็บหลักอยู่ที่ `src/app/page.tsx` เป็น Client Component สำหรับแบบฟอร์ม:

1. เพิ่มฟิลด์ใน type เช่น `Book` และ `BookForm`
2. เพิ่มค่าเริ่มต้นใน `emptyBookForm`
3. เพิ่ม `<label>` และ input ในฟอร์ม โดยผูก `value` กับ state และใช้ `onChange`
4. เพิ่มฟิลด์ลง `FormData` ใน `handleBookSubmit`
5. ปรับ API ให้ตรวจและบันทึกฟิลด์นั้น
6. เพิ่มการแสดงค่าฟิลด์ในรายการหนังสือ
7. หากแก้ไขข้อมูล ให้ใส่ค่าฟิลด์ลง `setBookForm` ใน `startEditing`

ตัวอย่างช่องกรอกราคา:

```tsx
<label className="flex flex-col gap-1">
  ราคา
  <input
    min="0"
    name="price"
    onChange={(event) =>
      setBookForm((current) => ({ ...current, price: event.target.value }))
    }
    step="0.01"
    type="number"
    value={bookForm.price}
  />
</label>
```

เรียก API จาก Client Component ด้วย `fetch` แล้วตรวจ `response.ok`
เพื่อแสดงข้อความผิดพลาด ถ้าส่งไฟล์ให้ใช้ `FormData` และไม่ต้องกำหนด
`Content-Type` เอง เพราะเบราว์เซอร์จะกำหนด multipart boundary ให้

สไตล์พื้นฐานอยู่ที่ `src/app/globals.css` และใช้ Tailwind CSS 4
คลาส `@/` ใช้อ้างอิงไฟล์ภายใน `src/` ได้ เช่น `@/lib/prisma`

npm run build
