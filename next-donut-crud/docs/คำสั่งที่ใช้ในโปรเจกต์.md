# รวมคำสั่งที่ใช้ในโปรเจกต์

เปิด Terminal ที่โฟลเดอร์โปรเจกต์ก่อนรันคำสั่ง ตัวอย่าง:

```powershell
cd D:\next-donut-crud



npm ci
npx prisma generate
npx prisma db push
npm run dev
```

## ติดตั้งและเปิดเว็บ

```bash
npm install
```

ติดตั้ง package ตาม `package.json` ใช้ครั้งแรกหลัง clone โปรเจกต์ หรือเมื่อมี
การเปลี่ยน dependencies

```bash
npm run dev
```

เปิดเว็บไซต์สำหรับพัฒนา โดยปกติอยู่ที่ [http://localhost:3000](http://localhost:3000)
หยุดเว็บด้วย `Ctrl+C`

```bash
npm run build
npm run start
```

`build` สร้าง production build ก่อน ส่วน `start` เปิดเว็บจาก build ที่สร้างไว้แล้ว

## Prisma และฐานข้อมูล SQLite

ฐานข้อมูลอยู่ที่ `prisma/dev.db` และ schema อยู่ที่ `prisma/schema.prisma`

```bash
npx prisma format
```

จัดรูปแบบ schema ให้อ่านง่าย

```bash
npx prisma validate
```

ตรวจว่า schema ถูกต้อง

```bash
npx prisma generate
```

สร้าง Prisma Client ใหม่ ควรรันหลังเปลี่ยน schema

```bash
npx prisma db push
```

ปรับฐานข้อมูล SQLite ให้ตรงกับ schema หลังเพิ่ม/แก้ตารางหรือฟิลด์
ตรวจ schema ก่อนทุกครั้ง และสำรองฐานข้อมูลก่อนการเปลี่ยนแปลงที่อาจทำให้ข้อมูลหาย

```bash
npx prisma studio
```

เปิดหน้าเว็บสำหรับดู เพิ่ม แก้ไข และลบข้อมูลในฐานข้อมูล

คำสั่งย่อที่ตั้งไว้ใน `package.json`:

```bash
npm run db:generate
npm run db:push
npm run db:studio
```

## ตรวจโค้ด

```bash
npm run lint
```

ตรวจ lint ของไฟล์ใน `src/`

```bash
npm run typecheck
```

ตรวจ TypeScript แบบไม่สร้างไฟล์ output

ก่อนส่งงาน แนะนำให้รันชุดคำสั่งนี้:

```bash
npx prisma validate
npm run lint
npm run typecheck
npm run build
```

## Endpoint API ที่มีในโปรเจกต์

สำหรับเรียก API จากหน้าเว็บหรือเครื่องมือทดสอบ:

| Method | URL | ใช้ทำอะไร |
|---|---|---|
| `GET` | `/api/books` | ดูหนังสือพร้อมรีวิว |
| `POST` | `/api/books` | เพิ่มหนังสือ ส่งข้อมูลแบบ `multipart/form-data` |
| `GET` | `/api/books/:id` | ดูหนังสือหนึ่งรายการพร้อมรีวิว |
| `PUT` | `/api/books/:id` | แก้ไขหนังสือ ส่งข้อมูลแบบ `multipart/form-data` |
| `DELETE` | `/api/books/:id` | ลบหนังสือและรีวิวของหนังสือนั้น |
| `POST` | `/api/books/:id/reviews` | เพิ่มรีวิว ส่ง JSON: `rating`, `content` |
| `GET` | `/api/employees` | ดูรายชื่อพนักงาน |
| `POST` | `/api/employees` | เพิ่มพนักงาน ส่ง JSON |
| `PUT` | `/api/employees/:id` | แก้ไขพนักงาน ส่ง JSON |
| `DELETE` | `/api/employees/:id` | ลบพนักงาน |

ตัวอย่างเรียก API พนักงานจาก PowerShell ขณะเปิด dev server:

```powershell
$employee = @{
  firstName = "สมชาย"
  lastName  = "ใจดี"
  phone     = "0812345678"
  email     = "somchai@example.com"
  position  = "พนักงาน"
} | ConvertTo-Json

Invoke-RestMethod `
  -Uri "http://localhost:3000/api/employees" `
  -Method Post `
  -ContentType "application/json" `
  -Body $employee
```

## ลำดับทำงานเมื่อเพิ่มฟิลด์ในตาราง

1. แก้ model ที่ต้องการใน `prisma/schema.prisma`
2. รัน `npx prisma format`
3. รัน `npx prisma validate`
4. รัน `npx prisma db push`
5. รัน `npx prisma generate`
6. เพิ่มการตรวจ/อ่าน/บันทึกฟิลด์ใน API route ที่เกี่ยวข้อง
7. เพิ่มช่องกรอกและแสดงค่าบน `src/app/page.tsx`
8. รัน lint, typecheck และ build

หาก Prisma Client ถูกล็อกบน Windows ให้หยุด dev server ด้วย `Ctrl+C`
แล้วค่อยรัน `npx prisma generate` อีกครั้ง
